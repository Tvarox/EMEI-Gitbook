# Bay8004

Adapter that reads from an ERC-8004 registry, applies a weighted scoring blend, and exposes `scoreOf` to `EMEIInvoice` as the gate.

## Functions

### `scoreOf`

```solidity
function scoreOf(address account) external returns (uint256 score);
```

Returns the weighted score in `[0, 10000]`. **Not `view`** — it emits `ReputationChecked` for auditability.

```
finalScore = min(
  (rawScore × (txSizeWeight + timeDecayFactor + categoryWeight)) / 10000,
  10000
)
```

**Reverts:** `RegistryUnavailable()` if the configured ERC-8004 registry is unreachable.

**Events:** `ReputationChecked(account, score, threshold)`.

---

### `giveFeedback`

```solidity
function giveFeedback(address subject, uint256 invoiceId, uint256 amount) external;
```

Forwards positive feedback to the underlying ERC-8004 registry. Called by `EMEIInvoice` after every successful settlement, for both issuer and payer.

---

### `setRegistry`

```solidity
function setRegistry(address registry) external;
```

Owner-only. Switch the underlying ERC-8004 registry.

---

### `setWeights`

```solidity
function setWeights(
    uint256 txSizeWeight,
    uint256 timeDecayFactor,
    uint256 categoryWeight
) external;
```

Owner-only. Three weights must sum to `10000`. Defaults: `3000`, `2000`, `5000`.

---

### `getThreshold`

```solidity
function getThreshold() external view returns (uint256);
```

Returns the current `minReputation` enforced by `EMEIInvoice`. Convenience pass-through.
